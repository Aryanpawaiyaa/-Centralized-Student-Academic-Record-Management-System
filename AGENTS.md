# Project Guidelines & Preferences

- **Report & Documentation Formatting**:
  - Do NOT include redundant metadata tables (e.g., fields like Course, Faculty Mentor, Document Release, Specification Details, Date, etc.) at the beginning of Markdown documents or reports.
  - Start directly with the document title and transition straight into the Table of Contents or executive content.
  - Maintain clean, humanized, technical prose suitable for academic and production review.
